# 🔍 GitHub User Finder

A responsive web application that allows users to search for any GitHub profile by username and display their information, including profile picture, bio, repositories, followers, and following count.

## 🚀 Features

- 🔎 Search any GitHub user by username.
- 👤 Displays user avatar, name, bio, public repos, followers, and following.
- 📱 Fully responsive design using Bootstrap 5.
- ⚡ Fetch data dynamically from GitHub REST API.

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript (ES6+)** - Fetch API & Promises
